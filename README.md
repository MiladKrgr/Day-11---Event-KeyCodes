## توضیحات پروژه 📌
<!-- Project Description : استاندارد  -->
این پروژه یک تمرین کاربردی است که با هدف درک و مدیریت رویدادهای کیبورد در جاوااسکریپت 
(KeyboardEvent) ساخته شده است. با فشردن هر کلید روی صفحه، اطلاعات کلیدی شامل کاراکتر فشره‌شده، 
کد عددی (KeyCode) و شناسه فیزیکی کلید (Code) به صورت کارت‌های مجزا و واکنش‌گرا به کاربر نمایش داده می‌شود..


---
---
---


## ویژگی ها  
<!-- Features : استاندارد -->
- دریافت و نمایش آنی رویدادهای `keydown` در سطح پنجره (Window)
- تفکیک دقیق سه ویژگی `event.key`، `event.keyCode` و `event.code`
- استایل‌دهی مدرن با Flexbox و واحدهای نمایشی واکنش‌گرا (`100dvh`)
- طراحی تمیز، مینیمال و متمرکز روی تعامل کاربر

## Project Description 📌
<!-- Standard : Project Description  -->
This project is a practical exercise created with the aim of capturing and handling
keyboard events in JavaScript (KeyboardEvent). By pressing any key on the keyboard,
key information including the pressed character, numerical keycode, and physical key code
is displayed to the user through responsive, distinct cards.

---
---
---

## Features 🌏
<!-- Standard : features  -->
- Instant capture and display of keydown events across the window
- Clear separation of event.key, event.keyCode, and event.code properties
- Modern styling using Flexbox and viewport-relative units (100dvh)
- Clean, minimal design focused on user interaction

---
---
---


# Tech Stack ⚙
<!-- Standard : Tech Stack  -->
- HTML5 (Semantic Markup & DOM Template Literals)
- CSS3 (Flexbox, Positioning, Modern Units)
